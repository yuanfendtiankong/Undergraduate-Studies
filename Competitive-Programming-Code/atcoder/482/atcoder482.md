### **A - 字符计数与奇偶判断**

题意（根据代码整理）：给定一个字符串，统计其中小写字母 `o` 的数量。如果数量为奇数，输出 `odd`；否则输出 `even`。

思路：直接遍历字符串，遇到 `o` 就让计数器 `cnt` 加一。遍历结束后，用 `cnt % 2` 判断奇偶性即可。注意代码统计的是小写字母 `o`，不是数字 `0`。

例如字符串 `oxo` 中有 2 个 `o`，输出 `even`；字符串 `ooo` 中有 3 个 `o`，输出 `odd`。如果没有 `o`，计数为 0，也应输出 `even`。

设字符串长度为 $N$，时间复杂度为 `O(N)`。代码保存了整个字符串，空间复杂度为 `O(N)`，除此之外只使用 `O(1)` 的额外空间。

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    string str;
    cin >> str;
    int cnt = 0;
    for (auto x : str)
        if (x == 'o')
            cnt++;
    if (cnt % 2)
        cout << "odd" << endl;
    else
        cout << "even" << endl;
    return 0;
}
```

### **B - 枚举行、列和对角线**

题意（根据代码整理）：给定一个 $5\times5$ 的方格，其中部分位置已经标记为 `o`。每次可以把一个未标记的位置改成 `o`，求最少再标记多少个位置，才能让某一整行、某一整列或者某一条大对角线全部变成 `o`。

思路：我们不需要枚举具体修改哪些格子，只需要枚举最终填满的是哪一条线。

一共有 5 行、5 列和 2 条大对角线，也就是 12 条候选线。假设某条线上已经有 `cnt` 个 `o`，那么填满它还需要修改 `5 - cnt` 个位置。因此，只要找到这些线中已有 `o` 数量的最大值 `mx`，答案就是 `5 - mx`。

代码分四部分统计：

- 遍历每一行，检查 `mp[i][j]`。
- 遍历每一列，检查 `mp[j][i]`。
- 主对角线上的位置满足行号等于列号，即 `mp[i][i]`。
- 副对角线上的位置满足行号与列号之和等于 6，即 `mp[i][6 - i]`。这里的下标从 1 开始。

例如所有候选线中，最多的一条线上已经有 4 个 `o`，那么只需要再标记 1 个位置。如果已经存在一条全是 `o` 的线，答案就是 0。中心格同时属于多条线也不影响统计，因为这里是在分别比较每条线，还没有实际执行修改。

方格大小固定为 $5\times5$，时间复杂度和空间复杂度均为 `O(1)`。

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);

    char mp[6][6];

    for (int i = 1; i <= 5; i++)
        for (int j = 1; j <= 5; j++)
            cin >> mp[i][j];

    int mx = 0;
    for (int i = 1; i <= 5; i++)
    {
        int cnt = 0;
        for (int j = 1; j <= 5; j++)
            if (mp[i][j] == 'o')
                cnt++;
        mx = max(mx, cnt);
    }

    for (int i = 1; i <= 5; i++)
    {
        int cnt = 0;
        for (int j = 1; j <= 5; j++)
            if (mp[j][i] == 'o')
                cnt++;
        mx = max(mx, cnt);
    }

    int cnt = 0;
    for (int i = 1; i <= 5; i++)
        if (mp[i][i] == 'o')
            cnt++;
    mx = max(mx, cnt);
    // cout << cnt << endl;

    cnt = 0;
    for (int i = 1; i <= 5; i++)
        if (mp[i][6 - i] == 'o')
            cnt++;
    mx = max(mx, cnt);

    cout << 5 - mx << endl;

    return 0;
}
```

### **C - 排序与二分统计区间内的点**

题意（根据代码整理）：在一个 $H\times W$ 的网格中给出 $N$ 个点，第 $i$ 个点位于第 $r_i$ 行、第 $c_i$ 列。接下来有 $Q$ 次询问：

- `1 l r`：统计行号位于闭区间 $[l,r]$ 内的点数。
- `2 l r`：统计列号位于闭区间 $[l,r]$ 内的点数。

思路：行询问只关心行号，列询问只关心列号，所以我们可以把每个点的两个坐标拆开保存。用数组 `a` 存所有行号，用数组 `b` 存所有列号，再分别排序。排序后不需要保留行号与列号之间的对应关系，因为每次询问只限制其中一个坐标。

对于排好序的数组，统计闭区间 $[l,r]$ 内的元素个数，可以使用两次二分：

- `lower_bound(..., l)` 找到第一个**大于等于** `l` 的位置 `L`。
- `upper_bound(..., r)` 找到第一个**大于** `r` 的位置 `R`。

那么下标区间 $[L,R)$ 中的元素恰好都在 $[l,r]$ 内，答案就是 `R - L`。右端点必须使用 `upper_bound`，这样才能把等于 `r` 的点也计算进去。

例如排序后的行号为 `[1, 2, 2, 5, 7]`，询问行号在 $[2,5]$ 内的点数。`L = 1`，`R = 4`，所以答案是 3。同一行可以有多个点，因此数组中的重复坐标必须保留，不能去重。

代码读入的 `h`、`w` 表示网格范围，之后不参与计算。我们只存储这 $N$ 个点的坐标，不需要建立整个二维网格。

排序的时间复杂度为 `O(N log N)`，每次询问的时间复杂度为 `O(log N)`，总时间复杂度为 `O(N log N + Q log N)`，空间复杂度为 `O(N)`。

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);

    int h, w, n, q;
    cin >> h >> w >> n >> q;

    vector<int> a, b;
    for (int i = 0; i < n; i++)
    {
        int r, c;
        cin >> r >> c;
        a.push_back(r);
        b.push_back(c);
    }

    sort(a.begin(), a.end());
    sort(b.begin(), b.end());

    for (int i = 0; i < q; i++)
    {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 1)
        {
            int L = lower_bound(a.begin(), a.end(), l) - a.begin();
            int R = upper_bound(a.begin(), a.end(), r) - a.begin();
            cout << R - L << endl;
        }
        else
        {
            int L = lower_bound(b.begin(), b.end(), l) - b.begin();
            int R = upper_bound(b.begin(), b.end(), r) - b.begin();
            cout << R - L << endl;
        }
    }
    return 0;
}
```

### **D - 僵尸感染与相向移动**

题意：数轴上有 $N$ 个人，第 $i$ 个人的初始坐标为 $X_i$。题目保证 $X_1<X_2<\cdots<X_N$，并且所有坐标都是偶数。

对于每个 $k=1,2,\ldots,N$，分别考虑：在时刻 0，第 $k$ 个人变成僵尸，其余人仍是人类。所有人类和僵尸都可以在数轴上自由移动，速度不超过 1；当人类与僵尸处于同一个坐标时，人类也会变成僵尸。求通过安排所有人的移动，使所有人都变成僵尸的最短时间。

思路：这里可以安排**人类和僵尸一起移动**，所以人类也可以主动靠近僵尸。两者相向而行时，接近速度为 2，初始相距 $d$ 就可以在 $d/2$ 的时间后相遇。

但是，初始只有一个僵尸，它不能同时向左右两边移动。关键在于：**先感染一个人，得到两个僵尸后，就可以分别向左右两边传播。** 对于中间位置，只需比较先感染左侧和先感染右侧这两种情况。

**1. 先感染左邻居。**

设当前初始僵尸为第 $k$ 个人，定义：

$$
L=X_k-X_1,\qquad R=X_N-X_k
$$

$$
d_l=X_k-X_{k-1},\qquad d_r=X_{k+1}-X_k
$$

让初始僵尸向左走，左边的所有人类向右走，右边的所有人类向左走。初始僵尸和左邻居相向而行，在时刻 $d_l/2$、坐标 $X_k-d_l/2$ 相遇。之后，让这两个僵尸分别向左、向右移动。

- **向左传播：** 向左走的僵尸相当于一直从 $X_k$ 向左移动，与最左侧的人相向而行。因此左侧全部感染需要的总时间为 $L/2$。
- **向右传播：** 先向左走了 $d_l/2$ 的时间，再从相遇处向右走。设从时刻 0 开始经过了 $t$，这个向右走的僵尸位于 $X_k+t-d_l$，最右侧的人位于 $X_N-t$。两者相遇时满足：

$$
X_k+t-d_l=X_N-t
$$

所以右侧全部感染需要的总时间为：

$$
t=\frac{R+d_l}{2}
$$

左右两边是在第一次感染后同时传播的，因此取两边完成时间的**最大值**，不是相加。先感染左邻居的方案为：

$$
T_l=\max\left(\frac L2,\frac{R+d_l}{2}\right)
=\frac{\max(L,R+d_l)}2
$$

这里的时间都从时刻 0 开始计算，不需要再额外加一次 $d_l/2$。同一侧的其他人都比最远端的人更早遇到对应方向的僵尸，所以检查两端就足够了。

**2. 先感染右邻居。**

同理，让初始僵尸先向右，与右邻居相遇后再分头传播，可以得到：

$$
T_r=\max\left(\frac R2,\frac{L+d_r}{2}\right)
=\frac{\max(R,L+d_r)}2
$$

两种方案取较小值，就是代码中的公式：

$$
ans_k=\min\left(\frac{\max(L,R+d_l)}2,
\frac{\max(R,L+d_r)}2\right)
$$

**3. 为什么其他移动方式不会更快？**

上面给出了可以实现的方案，还需要说明它们已经最优。

首先，感染只能通过速度不超过 1 的移动传播。从 $X_k$ 出发，时刻 $t$ 能传播到的最左位置不会小于 $X_k-t$；最左侧的人即使全速向右，也最多到达 $X_1+t$。因此，感染最左侧的人至少需要 $L/2$ 的时间。

再考虑第一次新增感染发生在左侧的任意一种方案。设相遇时刻为 $\tau$，相遇坐标为 $p$。被感染的人初始坐标不超过 $X_{k-1}$，速度不超过 1，因此：

$$
p\le X_{k-1}+\tau
$$

第一次感染时，所有僵尸都在 $p$；从此以后，即使继续感染并分头移动，时刻 $t\ge\tau$ 的感染传播范围最右也只能到达：

$$
p+(t-\tau)\le X_{k-1}+t
$$

而最右侧的人在被感染前，其坐标至少为 $X_N-t$。要让两者能够相遇，必须满足：

$$
X_N-t\le X_{k-1}+t
$$

也就是：

$$
t\ge\frac{X_N-X_{k-1}}2=\frac{R+d_l}2
$$

所以，只要第一次感染发生在左侧，完成时间就至少为 $T_l$，前面先感染左邻居的方案恰好能达到这个下界。第一次感染发生在右侧时，同理可得下界 $T_r$，也有对应方案能够达到。第一次感染必然发生在这两侧之一，因此比较这两个值就覆盖了所有可能。

例如坐标为 `[0, 8, 10, 20]`，让坐标 10 的人最先变成僵尸，则 `L = 10`、`R = 10`、`dl = 2`、`dr = 10`。先感染左邻居时，两侧完成时间分别为 5 和 6，整体需要 6；先感染右邻居时，需要 10。因此答案为 6。

**4. 端点和整数处理。**

如果初始僵尸在最左端或最右端，其他人都在同一侧，直接让僵尸与所有人类相向移动即可。最后遇到最远端的人，答案为：

$$
\frac{X_N-X_1}{2}
$$

当 $N=1$ 时，初始就已经全是僵尸，这个公式也会得到 0。

题目保证所有 $X_i$ 都是偶数，因此 `L`、`R`、`dl`、`dr` 都是偶数，公式中的除以 2 都可以整除，**不涉及向下取整造成的误差**。输入坐标已经严格递增，不需要排序。代码使用 `long long` 保存坐标和距离。

每个位置只需常数次计算，总时间复杂度为 `O(N)`，空间复杂度为 `O(N)`。

```c++
#include <bits/stdc++.h>

using namespace std;
#define ll long long
#define endl '\n'
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    vector<ll> x(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> x[i];

    for (int i = 1; i <= n; i++)
    {
        if (i == 1 || i == n)
        {
            cout << (x[n] - x[1]) / 2 << endl;
            continue;
        }

        ll L = x[i] - x[1];
        ll R = x[n] - x[i];

        ll dl = x[i] - x[i - 1];
        ll dr = x[i + 1] - x[i];

        cout << min(max(L, R + dl) / 2, max(R, L + dr) / 2) << endl;
    }

    return 0;
}
```
