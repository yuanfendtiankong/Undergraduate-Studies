## AtCoder Beginner Contest 478

### **A - Grapes**

题意：有N个人，编号为1到N，现在要把M颗葡萄分给他们。每次按照1, 2, ..., N的顺序，每人分一颗，分到第N个人以后再从第1个人开始，直到所有葡萄分完。最后输出每个人分到了多少颗葡萄。

思路：这个题直接按照题意模拟就可以了。我们用数组记录每个人分到的葡萄数量，每分出去一颗，就移动到下一个人。到达最后一个人以后，又需要回到第一个人，所以可以使用取模来实现循环。

代码中数组下标从0开始，`i` 表示已经分出了多少颗葡萄，那么下一颗就分给下标为 `i % n` 的人。例如N=3、M=5时，下标依次是0, 1, 2, 0, 1，所以最后每个人得到的数量是2, 2, 1。注意输出时每个人的数量各占一行。

因为M最多只有10000，逐颗模拟完全可以通过。时间复杂度为 `O(M + N)`，空间复杂度为 `O(N)`。

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    int n, m;
    cin >> n >> m;

    vector<int> ans(n + 1, 0);
    int i = 0;
    while (m)
    {
        ans[i % n]++;
        i++;
        m--;
    }
    for (int i = 0; i < n; i++)
        cout << ans[i] << endl;

    return 0;
}
```

### **B - Topping**

题意：拉面店有N种配料，第i种配料的价格是i，快乐值是 \(W_i\)。我们需要选择恰好三种不同的配料，并且总价格不能超过V，问我们能够得到的最大快乐值是多少。题目保证至少存在一种合法的选择。

思路：最开始看到“价格不能超过V，还要让快乐值最大”，可能会想到背包，但是这个题只需要选三种配料，而且N最多是100，所以直接枚举这三种配料就足够了。

我们用三重循环枚举编号i、j、k，并让它们满足 `i < j < k`。这样既保证选择的是三种不同的配料，又不会把同一组配料按照不同顺序重复枚举。对于每组选择，如果 `i + j + k <= v`，就用 `w[i] + w[j] + w[k]` 更新答案。

注意这里**价格是配料编号，数组w存的是快乐值**，所以判断预算时比较的是编号之和，不是快乐值之和。N=100时只会枚举161700种组合，时间复杂度为 `O(N^3)`，空间复杂度为 `O(N)`。

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    int n, v;
    cin >> n >> v;
    vector<int> w(n + 1);

    for (int i = 1; i <= n; i++)
        cin >> w[i];

    int ans = 0;
    for (int i = 1; i <= n; i++)
    {
        for (int j = i + 1; j <= n; j++)
        {
            for (int k = j + 1; k <= n; k++)
            {
                if (i + j + k <= v)
                    ans = max(ans, w[i] + w[j] + w[k]);
            }
        }
    }
    cout << ans << endl;

    return 0;
}
```

### **C - Sort Subarray**

题意：给我们一个长度为N的整数数组A，以及一个整数K。我们必须进行恰好一次操作：选择一个长度为K的连续区间，把这个区间中的元素按升序排序。问能不能通过这一次操作，让整个数组都变成升序，也就是满足 \(A_i \le A_{i+1}\)。数组中可能有重复元素。

思路：这个题最开始可以想到暴力枚举区间。我们尝试每一个起点，复制数组、排序对应的K个元素，再检查整个数组是否有序。但是这样会重复排序很多次，最坏时间复杂度达到 `O(N^2 log N)`，而N可以达到 `2 × 10^5`，显然不能这样做。

**第一步：先想清楚，我们最后到底要得到什么数组？**

虽然可以选择不同的区间，但如果操作后整个数组有序，那么最终的数组是确定的：它一定等于把原数组完整排序后的结果。

所以我们先复制一份数组B，然后把B完整排序。接下来不急着枚举区间，而是比较A和B，看看哪些位置还没有到它们应该在的状态。

例如：

| 位置 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 原数组A | 1 | 4 | 3 | 2 | 5 |
| 目标数组B | 1 | 2 | 3 | 4 | 5 |

这里第2、4个位置不同，因此这两个位置必须被修改。

**第二步：哪些位置必须包含在操作区间内？**

一次排序只能改变我们选中的区间，区间外的元素完全不会动。因此，如果某个位置满足 `a[i] != b[i]`，这个位置就必须在操作区间里，否则它永远无法变成目标值。

我们记录第一个不同的位置L，以及最后一个不同的位置R。操作区间是连续的，所以必须包含整个 `[L, R]`，即使中间有些位置本来就是正确的，也不能跳过去。

因此，如果：

\[
R - L + 1 > K
\]

就说明长度为K的区间放不下所有需要修改的位置，答案一定是 `No`。

**第三步：跨度不超过K，为什么就一定可以？**

如果 `R - L + 1 <= K`，我们可以把 `[L, R]` 向两边适当扩展，选出一个长度恰好为K、并且包含它的合法区间。靠近数组边界时向另一边补足即可。

这个区间外没有错位位置，所以A和B在区间外已经完全相同。又因为B本来就是A排序得到的，两者整体包含的元素以及每个元素出现的次数都相同。扣除区间外相同的部分，区间内的元素及其次数也必然相同。

而B的这个区间已经有序，所以把A的这个区间排序以后，一定会得到B中对应的部分。这样区间内外就都和B一致，整个数组也就有序了。

所以，**首尾错位位置的跨度不超过K，就是能够完成操作的条件。** 这个结论对重复元素也成立。

在上面的例子中，L=2、R=4，跨度为3。K=3时，排序第2到第4个元素即可；K=2时，无论选哪个区间，都无法同时修改第2和第4个位置。

**第四步：注意原数组已经有序的情况。**

如果A和B完全相同，答案直接是 `Yes`。虽然题目要求恰好操作一次，但已经有序的数组中，任意一个长度为K的区间也都有序，再排序一次不会改变数组。

你下面的代码把 `mn` 初始化为 `1e8`，`mx` 初始化为0。如果没有不同位置，它们就不会更新，算出的 `cnt` 是负数，因此会进入 `cnt <= k` 并输出 `Yes`。这个结果是正确的，不过这里的负数只是初始值未更新造成的，不能把它理解成真实的区间长度。

最后把流程串起来就是：复制A得到B并排序 → 找到首尾不同的位置 → 判断这两个位置的跨度是否不超过K；如果没有不同位置，则本来就已经有序。

时间复杂度主要来自对B的排序，为 `O(N log N)`；需要保存两个数组，空间复杂度为 `O(N)`。

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    int n, k;
    cin >> n >> k;
    vector<int> a(n + 1), b(n + 1);
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        b[i] = a[i];
    }
    sort(b.begin() + 1, b.end());
    int mn = 1e8, mx = 0;
    for (int i = 1; i <= n; i++)
    {
        if (a[i] != b[i])
        {
            mn = min(mn, i);
            mx = max(mx, i);
        }
    }
    // cout << mx << " " << mn << endl;
    int cnt = mx - mn + 1;
    if (cnt <= k)
        cout << "Yes" << endl;
    else
        cout << "No" << endl;

    return 0;
}
```

### **D - Range Set Insertion Query**

题意：起初我们有N个空Set $S_1, S_2, \ldots, S_N$ 接下来我们要对这N个set进行Q次操作，每次操作往$L_i$和$R_i$范围内的$S$ set添加$X_i$这个数，问我们经历过若干次操作后，我们每个Set中都有多少个数字。

思路：读完题模拟了一下数据，我们很容易想到差分，因为最后统计的是我们每个Set中会有多少个数字，因此每次操作可以当成在$L_i$和$R_i$范围内的$S$ set +1，最后我们做一次前缀和就可以得到我们最后的结果了吗？

NO！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！！

本题最麻烦的一个地方就是我们的$X_i$是可以能重复的，也就是我们可能会在某个区间的范围内加入若干次我们相同的某个数字。那么，既然这样直接做是不对的，那我们该如何去处理我们的这个插入呀。

既然我们可能会在部分区间添加多次我们的$X_i$那我们是不是可以提前处理一下我们的区间，让可能会造成重复添加的区间不在重复添加，也就是合并我们添加相同$X_i$的区间，这样我们就不会再出现一个区间添加两次$X_i$了，这里我要强烈推荐一下我的区间合并模板，真的好用。

#### 区间合并模板：

```c++
vector<pair<int, int>> b;
//处理输入输出
sort(b.begin(), b.end());
vector<pair<int, int>> tmp; //合并后的新区间数组
for (auto c : b)
{
    if (tmp.empty() || c.first > tmp.back().second)
        tmp.push_back({c.first, c.second});
    else
        tmp.back().second = max(tmp.back().second, c.second);
}
```

完整代码：

```c++
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);

    int n, q;
    cin >> n >> q;

    vector<int> ans(n + 1, 0);
    map<int, vector<pair<int, int>>> cnt;
    for (int i = 0; i < q; i++)
    {
        int l, r, x;
        cin >> l >> r >> x;
        cnt[x].push_back({l, r});
    }

    for (auto [a, b] : cnt)
    {
        sort(b.begin(), b.end());
        vector<pair<int, int>> tmp;
        for (auto c : b)
        {
            if (tmp.empty() || c.first > tmp.back().second)
                tmp.push_back({c.first, c.second});
            else
                tmp.back().second = max(tmp.back().second, c.second);
        }

        for (int i = 0; i < tmp.size(); i++)
        {
            ans[tmp[i].first]++;
            if (tmp[i].second + 1 <= n)
                ans[tmp[i].second + 1]--;
        }
    }

    for (int i = 1; i <= n; i++)
        ans[i] += ans[i - 1];
    for (int i = 1; i <= n; i++)
        cout << ans[i] << " ";

    return 0;
}
```
